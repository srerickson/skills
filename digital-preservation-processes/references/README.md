# References: EOSC EDEN Core Preservation Processes (CPPs)

This directory contains reference markdown documentation for the 30 Core Preservation Processes (CPPs) established by the **EOSC EDEN project** (Horizon Europe Project Number 101188015).

These reference documents define the input requirements, output metadata, step sequences, rationale, relationship linkages, and international framework mappings for each process.
